# 🎚️ BBS Curve Fixer

Аддон к моду **BBS**. Делает настройки шейдеров нормально анимируемыми.

## Чинит

- **Анимировать можно было почти ничего** — только те опции, которые автор пака пометил как ползунки (обычно 2–3 из сотен). Теперь доступна **любая дробная настройка**: у Photon это разница между ~2 опциями и почти 300.
- **Опции за галочками включения не работали.** Теперь работают — например фокус ГРИП (`DOF_FOCUS_DISTANCE`) у Complementary раньше анимировать было нельзя, а теперь можно.
- **Кривые солнца, яркости, погоды и цвета неба работали только в редакторе** — при обычном проигрывании фильма в мире они молча ничего не делали. Теперь работают везде.

## Добавляет

- **Нормальное окно выбора настроек** вместо плоского списка сырых названий. Повторяет меню шейдера из Iris: те же экраны, вкладки, колонки и переключатели. Клик по настройке — добавляет кривую, уже анимированные обведены зелёным, старый список доступен одной кнопкой.
